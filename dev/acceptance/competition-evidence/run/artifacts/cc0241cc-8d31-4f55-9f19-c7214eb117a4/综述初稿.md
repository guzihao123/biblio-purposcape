# 领域格局与七类双槽选题

本对话仅使用四篇 HCC 离线摘要，把髓系代谢、IL-8/CXCR2、乳酸化和免疫微环境综述分别呈现，不将跨研究线索写成联合疗效。
- S1P 机制与耐药有摘要证据 [1]。
- IL-8/CXCR2 与髓系状态有摘要证据 [2]。
- 乳酸化/MVP 与 PD-L1 稳定性有摘要证据 [3]。
- 研究空白：三条机制链未在同一体系内联合验证 [1][2][3]。
- 研究空白：循环指标与组织机制的外推边界仍需复核 [2]。
- 研究空白：联合干预效果未由池内摘要建立 [1][3]。

## 研究空白与要点

| 研究空白 | 机制/数据/方法/需求理由 | 文献证据 |
|---|---|---|
| 三条机制链未在同一实验体系内联合验证 | 研究对象、方法和终点不同 | [1][2][3] |
| 循环指标与组织机制的外推边界未解决 | 关联与因果证据层级不同 | [1][2][3] |
| 联合干预效果没有池内摘要支持 | 不能把互补机制等同于协同疗效 | [1][2][3] |
