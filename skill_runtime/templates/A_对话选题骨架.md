# 模板 A · 仅对话七类双选题骨架

用法：仅用于模式 A 的「仅对话中给要点和代表文献」。逐槽填写，证据不足时按下方规则替换为未推荐槽位，不凑数。完成后运行 `python3 verify_delivery.py 综述初稿.md 1500-4000 --mode A_DIALOGUE`。

实际选题槽位统一写成：

```markdown
- 选题 1｜类内第 1 推荐｜【题目】
  核心研究问题：【研究对象×关键变量×要回答什么】
  文献依据与机会：【对应该类哪条要求及具体空白】[n]（分析）
  数据可得性：【来源与限制；未确认就写未确认】
  研究价值：【】；可行性：【】；创新潜力：【】；实施难度：【】（分析）
```

无法推荐时统一写成：

```markdown
- 选题 2｜未推荐
  原因：【缺什么必要证据、为何候选重复或不成立、需要什么补充条件】
```
