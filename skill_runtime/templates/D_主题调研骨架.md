# 模板 D · 主题调研骨架（组会调研·正文九段）

用法：复制到输出目录；正文按九段组织、精读页 3–5 张、总 3000–6000 字，落盘 `调研初稿.md`；完成后跑 `verify_delivery.py 调研初稿.md 3000-6000 --mode D`。交付形式选展示 PPT 时提纲先出 PPT 目录（页码/结论式标题/核心观点/展示内容/**实际图表资产与来源**/对应文献 [n]，按 `D_PPT骨架.md` 组织第 1/2/3/4/5/6/8 部分；第八部分含 1–2 个优先方向与下一步建议），PPT 抽取文本另存 `汇报文本.md` 跑证据核验（1500-4000，不传 --mode），并用 `ppt_asset_manifest.json` + `verify_ppt_delivery.py` 核验真实图表与结构。首段=调研范围与核心结论先行；构件齐了才写粘合散文；区分文献结论 [n]／调研者归纳（"分析"）／未来设想（"设想"或【待核实】）；检索概况必须取自 search_log 与 stats_*.json 真实数据；原文图走三档出口（pdf_figures.py 自动裁图 / 人工补图 figures/ / 实际尝试失败后的降级【待核实】），不伪造；阅读深度分“仅摘要/摘要＋原文图/已读全文”，读过全文的精读页可在 evidence_ledger 第 5/6 列补全文定位与全文原句（verify ③全文通道额外回验，未填或文件缺失自动回落摘要通道）。
